# STATS 451 Final Project: Bayesian Modeling of Methane Emissions

**Authors:** Sirui Chen, Yingxi Chen, Jiayu Feng, Qiyun Teng  
**Course project:** STATS 451, 2024

This repository contains the analysis and report materials for a group project examining methane emissions using exploratory data analysis and Bayesian regression in R and Stan.

## Repository contents

- `STATS451_final_eda.Rmd` — data cleaning, exploratory analysis, and visualization
- `STATS451_final_model.Rmd` — Bayesian model specification, sampling, diagnostics, sensitivity analysis, and inference
- `STATS451_Final_Report.pdf` — final project report
- `STATS451_final_model.pdf` — rendered modeling output
- `STATS_451_final_eda.pdf` — rendered exploratory analysis
- `Group Contribution Report.docx` — group contribution documentation
- `data/` — project data

## Methods

The project uses R, Stan, `rstan`, `bayesplot`, and the tidyverse to analyze methane emissions, including model diagnostics and prior-sensitivity checks.

## Scope

This is a collaborative course project. Author order and project materials are preserved as submitted.
